# Security Policy

## Supported versions

Helicon is pre-release. Security fixes land on `main` first.

| Version | Supported |
| ------- | --------- |
| `main` (pre-release) | ✅ |
| tagged releases | ✅ latest only |

## Reporting a vulnerability

Open a **private** report via GitHub Security Advisories. Do not open a public issue for credentials, auth bypass, sandbox escape, or WSL command-injection concerns.

Please include: repro steps, OS (Windows/WSL2, macOS, Linux), `muse --version`, and whether approval modes were bypassed.

We will acknowledge within 72 hours and coordinate disclosure.
