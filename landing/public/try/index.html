Try Helicon in your browser

The Helicon demo runs the real Helicon interface for Meta's Muse Code CLI in your browser, on sample data. The demo needs no install, no Muse Code account and no subscription. In the demo you can open threads, approve a tool call, read diffs, check usage and cost, and watch a background monitor. Nothing runs on your machine and no model is called.

Last updated 17 October 2026

What the Helicon demo includes

  • Three sample projects, readme-demo, api-server and helicon, each with seeded threads.
  • A thread waiting on an approval, with Allow and remember, Allow once and Reject.
  • Tool calls and inline diffs for file reads, edits and shell commands.
  • A usage page that shows what each thread would have cost at API rates, by day, by model and by thread.
  • A Muse Code monitor that watches a pull request's checks in the background.
  • The command palette and the settings page.

How to use the demo

  1. Open helicon.sh/try. The sample projects load in the sidebar.
  2. Open the thread "Paginate GET /v1/projects with a cursor". It is waiting on an approval.
  3. Choose Allow once to run the tests, or Reject to skip them.
  4. Open the usage page to see the cost of each thread at API rates.
  5. Press Cmd+K on macOS, or Ctrl+K on Windows and Linux, to open the command palette.

Worked example: approve a test run

In the api-server project, the prompt asks Muse Code to paginate GET /v1/projects with a cursor and then run the route tests. Muse Code reads src/routes/projects.ts, edits the route to take limit and cursor query parameters, and stops before npm test -- routes/projects, because a shell command needs your approval.

Choose Allow once and the tests run. Both route tests pass, and the reply says the route now takes limit (default 50, max 200) and cursor and answers { data, next }. Choose Reject and the tests do not run. The reply then points you to the change in src/routes/projects.ts.

Limits of the demo

  • Every project, thread, usage figure and reply is sample data. A prompt you send gets a fixed reply, not an answer from a model.
  • The demo cannot open folders on your computer or reach a Muse Code install.
  • Threads you start live in memory and are gone after a reload.

Use Helicon on your own projects

Helicon is free and MIT licensed. Download the desktop app for Windows, macOS or Linux, or install the VS Code extension. Both run on the Muse Code subscription you already have.
